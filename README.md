A responsive, high-performance website built with Tailwind CSS, modern typography, and interactive JavaScript features for the **Dell Exclusive Showrooms in Chennai** (Authorized Dealer: **Gainz India Peripherals Private Limited**).

---

## 🚀 How to Run / View

### Option 1: Double-Click (Immediate)
Simply double-click the file [index.html](file:///c:/Users/DELL/Downloads/dell-exclusive-store/index.html) to open it in Chrome, Edge, Brave, or Firefox.

### Option 2: Run a Local Dev Server (PowerShell)
```powershell
cd "c:\Users\DELL\Downloads\dell-exclusive-store"
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
